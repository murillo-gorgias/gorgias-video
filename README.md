# gorgias-video

A Claude skill for making Gorgias videos from brief to finished file.

- `SKILL.md`: the workflow. Claude reads this first.
- `SETUP.md`: the tools to install once per computer.
- `reference/`: one file per step. Craft and brand rules.
- `reference/tools/capture-pipeline.md`: how a video is built as a web page and photographed frame by frame.
- `scripts/`: the repeatable jobs as ffmpeg, Python and Node scripts: capture, music, mixing, checks, exports.
- `examples/starter/`: a short working video to copy for each new one.
- `review/`: a review page where people pin notes to exact frames of a rendered video.
